# הגדרות שרת

כל המספרים של המוד נמצאים בקובץ אחד, **`world/serverconfig/enhanced-server.toml`** בתיקיית העולם (או השרת). המוד יוצר אותו כשהעולם נטען בפעם הראשונה, עם כל האפשרויות בברירת המחדל שלהן, ומסנכרן אותו ללקוחות. זה קובץ טקסט רגיל: פותחים אותו בכל עורך, משנים ערך ומפעילים מחדש את העולם או את השרת.

בקובץ יש חלק לכל גיבור (לבוס יש חלק לקרב שלו וחלק לגיבור שלו, ו-`[boss]` מחזיק את החוקים שכל הבוסים חולקים; ל[קסם בנייה](#קסם-בנייה) יש שלושה; ל[דרך המכשפות](#דרך-המכשפות), ל[ספר הווישאנטי](#ספר-הווישאנטי), ל[דארקהולד](#הדארקהולד), ל[רוני ההקס](#רוני-ההקס) ול[יוצר הגיבורים](#יוצר-הגיבורים) יש חלקים משלהם), ואפשרות נכתבת בצורה `חלק.מפתח`. למשל, הסיכוי למות בהקס של וונדה הוא המפתח `hexDeathChance` בחלק `[scarlet_witch]`:

<div dir="ltr">

```toml
[scarlet_witch]
    hexDeathChance = 0.95
```

</div>

לכל מספר יש טווח ערכים מותר, וערך שמחוץ לטווח מאופס לברירת המחדל כשהקובץ נטען. *טיק* הוא 1/20 שנייה. תשישות אוכל של 4.0 עולה נקודת אוכל אחת. מהירויות תעופה הן ביחידות של מיינקראפט, שבהן תעופה בקריאייטיב היא 0.05.

אין למוד אפשרויות שרת מעבר לאלה שמופיעות כאן. כל השאר (מה נחשב מתכת, מה אפשר להרים, אילו בוסים עמידים) נקבע בתגיות של דאטה-פק: ראו [תגיות דאטה-פק](#תגיות-דאטה-פק) בהמשך.

## הוויז'ן של ההקס

החלק `[hex_vision]`. כשוונדה מקימה הקס, ויז'ן מופיע ונלחם לצדה (ראו [מכשפת השני](Scarlet-Witch-HE#הוויזן-של-ההקס)).

| אפשרות | ברירת מחדל | ערכים מותרים | משמעות |
|---|---|---|---|

## קסם בנייה

החלקים `[build_magic]`, `[build_magic_wanda]` ו-`[build_magic_billy]`. הדף הוא [קסם בנייה](Build-Magic-HE). בהערות, אפשרות של בילי או של וונדה נכתבת תמיד עם החלק שלה (`build_magic_billy.meter`), אף פעם לא כ-`billy.x`, שהוא החלק `[billy]` של שאר הכוחות שלו. המספרים של בילי הם של הדרגה הראשונה שלו, שוליה: הדרגות גדלות מהם. משפחה שרוצה אותו חזק כמו אמא שלו קובעת את תשעת מספרי האימון ל-0 ומד גדול (`maxRank` הוא כבר 10). כל ערך נקרא כשמשתמשים בו, כך שעריכת הקובץ משנה אותו מיד.

### `[build_magic]`: כל בונה

**היסטוריית הביטול** נכתבת לתיקיית העולם לפני שכל קסם משנה את העולם (כך שקריסה משאירה אותה ניתנת לביטול), תיקייה לכל שחקן. בזמן שקסם עובד, הצעד שלו נשמר שלם בזיכרון, בערך 14 בתים לבלוק; קסם שהצעד שלו לא היה נכנס ב-`undoMemoryMb` (או בחצי מ-`serverUndoMemoryMb`) נשמר כ*צעד קל*, רק סיבית לכל בלוק בזיכרון, והרשומות שלו בדיסק הן הצעד. זה דורש `undoSurvivesRestart` ורשומה שנכנסת ב-`undoDiskMb` (בערך חצי בית לבלוק); אחרת הקסם אומר *"גדול מדי לביטול אחר כך"* ורץ רק אם השחקן מחזיק את הכפתור הימני, ובלי ביטול. הזזה אף פעם לא קלה: היא נדחית. בהגדרות ברירת המחדל הקו בין שלם לקל הוא בערך 4 מיליון בלוקים. הגבולות נבדקים פעם בשנייה וכשקסם מסתיים. `/enhanced build forget` מנקה את של שחקן.

    bossMusic = true
    bossAtmosphere = true

</div>

החלקים `[apocalypse_shield]`, `[apocalypse_boss]` ו-`[apocalypse]`. **3.2: הכפתור הראשי.** `apocalypse_boss.powerFactor` (0.65 כברירת מחדל) מכפיל כל נזק שהוא והפרשים שלו עושים ואת מספר החניתות, הפרשים והמערבולות שלו (מעגלים כלפי מעלה, אף פעם לא מתחת לאחד), ומחלק את מהירות ההתקפות שלו (ההפסקה בין שתי התקפות וכל קולדאון נמשכים פי 1 חלקי powerFactor). הוא לא נוגע בחיים, בשריון, במגן, בחלונות, בחומת החול או בגיבור. ב-1.0 הוא אפוקליפסה של 3.1 בכל מה שהוא מכפיל. אפשרויות הנזק למטה הן המספרים לפני הגורם. הקרב עצמו והגיבור מתוארים בדף של אפוקליפסה: [אפוקליפסה](Apocalypse-HE). המספרים המשותפים לכל הבוסים (כמה קרבות רצים בו זמנית, שעוני הכישלון והנטישה, הזמן המינימלי לתגמול, הניסיון, מגבלת הזמן והגנת הזירה) נמצאים בחלק `[boss]`.

## מבנים

לשלושת המבנים של 3.3 ([מוצבים של הידרה, המכתשים של מיולניר ובית הספר למוטנטים](Structures-HE)) **אין אפשרות שרת**: הם דאטה, כך שדאטה-פק מכוונן אותם. `data/enhanced/worldgen/structure_set/` מחזיק את המרווח וההפרדה שלהם (`hydra_outposts` 36 / 12 צ'אנקים, `mjolnir_craters` 32 / 10, `mutant_schools` 40 / 14; מוצבים ומכתשים שומרים 6 צ'אנקים מבית ספר), תגיות הביומות `data/enhanced/tags/worldgen/biome/has_structure/hydra_outpost.json`, `mjolnir_crater.json` ו-`mutant_school.json` אומרות איפה הם עומדים (מרוקנים תגית כדי לעצור את המבנה הזה בצ'אנקים חדשים), `data/enhanced/worldgen/structure/` מחזיק את המבנים עצמם (`max_slope`, ה-`radius` וה-`depth` של המכתש), `data/enhanced/structure/` את תבניות הבניינים, ו-`data/enhanced/loot_table/chests/hydra_outpost/` ו-`chests/mutant_school/` את מה שיש בתיבות.

## אפשרויות לקוח: אנימציות, אפקטים ומראה

תשע אפשרויות נוגעות רק למשחק שלכם. הן לא מסונכרנות, ושרת לא יכול לשנות אותן. הן נמצאות בקובץ שני, **`config/enhanced-client.toml`** בתיקיית מיינקראפט שלכם (המוד יוצר אותו בפעם הראשונה שהמשחק מתחיל), בחלקים `[animation]`, `[appearance]` ו-`[build_magic]` (האחרון הוא ל[קסם בנייה](Build-Magic-HE); תנועה מופחתת מרגיעה גם את האנימציות שלו ואת הזרמים של המשיכה המגנטית). הדרך הקלה לשנות אותן היא מתוך המשחק: **Mods ← Enhanced ← Config**. אפשר גם לשנות ערך בכל עורך טקסט כשהמשחק סגור:

<div dir="ltr">

```toml
[animation]
    animations = true
    reducedMotion = false
    flightEffects = true

[appearance]
    hideHeroArmour = true

[build_magic]
    hints = true
    tips = true
    ghostDetail = 32768
    seeThrough = true
    showOthers = true
```

</div>

| אפשרות | ההגדרה בקובץ | ברירת מחדל | מה היא עושה |
|---|---|---|---|
| אנימציות גיבורים | `animations` | `true` | התנוחות המשולבות של הגיבורים, תעופה, ריצה, יכולות והנשק של ת'ור באגרוף שלו. כבוי: רק התנוחות הרגילות של מיינקראפט. |
| תנועה מופחתת | `reducedMotion` | `false` | אנימציה רגועה יותר: נדנוד ריחוף וסחף בשליש מהעוצמה, בלי ידיים רועדות, ריטוט או רעידות מצלמה, וטבעות עמומות יותר. |
| אפקטי תעופה | `flightEffects` | `true` | שובלים, טבעות, קווי רוח וגלי הלם סביב גיבורים שעפים, והנצנוצים הקטנים של כמה יכולות. כבוי: נשארים רק כמה חלקיקי שובל. |
| הסתרת השריון של גיבורים | `hideHeroArmour` | `true` | שחקנים עם כוח מצוירים בלי השריון שלהם (קסדה, שריון חזה, מכנסיים ומגפיים, עם העיטורים והצבע שלהם): שלכם בגוף שלישי, של כל השחקנים האחרים ובתצוגה המקדימה שבמלאי, כדי שהוא לא יסתיר את הדמויות. השריון ממשיך להגן כרגיל, ושחקן בלי כוח נראה כמו תמיד. האליטרה, דלעת מגולפת או ראש של מפלצת, והציוד של הגיבורים מהמוד הזה (הקסדה של מגנטו, הכתר של וונדה, המשקפיים של קוויקסילבר) תמיד מצוירים. כבוי: גיבורים מציגים את השריון שלהם כמו כולם. |
| רמזים לקסם הבנייה | `hints` | `true` | הפס עם תמונות העכבר והמקשים בפינה הימנית התחתונה בזמן שבונים. |
| טיפים לקסם הבנייה | `tips` | `true` | הטיפים הקטנים והמונפשים בפעמים הראשונות שמשתמשים בקסם. |
| פירוט התצוגה המקדימה | `ghostDetail` | `32768` | הכי הרבה בלוקים שמצוירים אחד אחד בתצוגה המקדימה של קסם (0 עד 262144): תצוגה גדולה יותר מצוירת רק מבחוץ, ואחר כך כקופסה צבועה. |
| לראות את המסגרת דרך קירות | `seeThrough` | `true` | המסגרת נראית קלוש דרך גבעות וקירות. |
| בונים אחרים | `showOthers` | `true` | רואים את המסגרות של בונים אחרים לידכם. |

עוד שתי אפשרויות לקוח, למוזיקה ולאווירה של הקרב מול תאנוס, נמצאות בחלק `[thanos]` של אותו קובץ: ראו [למעלה](#המשחק-שלכם-המוזיקה-והאווירה-של-הקרב).
