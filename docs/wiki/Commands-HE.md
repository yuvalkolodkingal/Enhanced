# פקודות

כל הפקודות מתחילות ב-`/enhanced` והן ל**אופרטורים** (רמת הרשאה 2): בעלי שרתים ושחקנים שיכולים להשתמש ב-`/gamemode`. (שתי פקודות קטנות הן לכולם: `/road leave` ו-`/road status`, בהמשך.) הכוחות של גיבורים הם קבועים, ולכן הפקודות האלה הן גם הדרך היחידה להוריד כוח. (היוצאות מן הכלל הן `/enhanced_anim`, `/enhanced_model` ו-`/enhanced_ultron_fx`, להסתכלות על האנימציות, על הבוסים ועל האפקטים של אולטרון: ראו בהמשך.)

| פקודה | מה היא עושה |
|---|---|
| `/enhanced power get [player]` | מראה איזה כוח יש לשחקן. בלי שחקן, היא מראה את שלכם. |
| `/enhanced power set <players> <power> [look]` | נותנת כוח או מורידה אותו, ואפשר ישר לאחד המראות שלו. |
| `/enhanced look <players> <look>` | משנה את המראה של כל שחקן שלגיבור שלו יש את המראה הזה. |
| `/enhanced hex list` | מציגה את כל ההקסים במימד הנוכחי (הבעלים, המיקום, הרדיוס וכמה שחקנים מורשים להיכנס). |
| `/enhanced hex clear` | מפרקת את כל ההקסים במימד הנוכחי. |
| `/enhanced boss start thanos [force]` | קוראת לטיטאן המטורף במקום שבו אתם עומדים, כמו הטסרקט והשרביט של לוקי: נפתח פורטל ואחרי שש שניות הוא נוחת 14 עד 20 בלוקים מכם. `force` מדלג על בדיקת המקום, על הכלל של העולם העליון, על המתג `summonEnabled` של השרת ועל המנוחה (שליו וקרב אחד בכל פעם עדיין חלים; אם נותנים את הפקודה באוויר, הקרב נעשה על הקרקע שמתחתיכם). ראו [תאנוס](Thanos-HE). |
| `/enhanced boss start ultron [force]` | בלי `force` זה הטקס בלי השרביט: צריך את תוכנית אולטרון ביד (והיא נגמרת), אולטרון מתעורר על הבלוק שאתם מסתכלים עליו, וכל הבדיקות נעשות. עם `force` הוא מתעורר ליד הרגליים שלכם בלי תוכנית, ובדיקות הקרקע מדולגות (לא השמיים הפתוחים, ואף פעם לא כשהוא כבוי בשרת, בשליו או כשקרב בוס אחר רץ). ראו [אולטרון](Ultron-HE). |
| `/enhanced boss start apocalypse [force]` | עם `force` מעירה את אן סבאח נור ליד הרגליים שלכם, בלי אבן פסגה, ומדלגת על הבדיקות של הקרקע, השמיים והצורך במכשפת השני או בפניקס (לא על קושי שליו, לא על המתג שמכבה אותו ולא על החוק של קרב אחד בכל פעם). בלי `force` הפקודה היא הטקס עצמו: צריך אבן פסגה ביד, בלוק בטווח ראייה וכל הבדיקות. ראו [אפוקליפסה](Apocalypse-HE). |
| `/enhanced boss stop` | מסיימת את קרב הבוס שרץ. תוכנית אולטרון או אבן פסגה שנגמרו מוחזרות, והאי של סוקוביה מוחזר למקומו. `stop` שני בזמן שבוס עוד עוזב מסיים אותו מיד. |
| `/enhanced boss list` | מציגה את קרבות הבוס הרצים. |
| `/enhanced boss cleanup <center> <radius>` | מסירה כל יצור וקליע מהסוג של בוס בטווח הזה, בין אם קרב שייך אליו ובין אם לא: את תאנוס, החרב, המטאורים, הכדורים והאשליות שלו; את אולטרון, הזקיפים (גם של אולטרון גיבור), הקליעים שלו ומפתח הוויברניום; את אפוקליפסה, החניתות, הסלעים והפקעות שלו. היא לא מסירה בלוקים. |
| `/enhanced build undo <player> [steps]` | מבטלת את הצעדים האחרונים של קסם בנייה של השחקן (אחד כברירת מחדל, מ-1 עד 1000), מהחדש לישן, כמו ה-Ctrl + Z שלו, עם אותו כלל בטוח: בלוקים שמישהו שינה מאז נשארים כמו שהם. הורה יכול לתקן טעות של ילד. ראו [קסם בנייה](Build-Magic-HE). |
| `/enhanced build stop [<player>\|all]` | עוצרת את קסמי הבנייה שעובדים, איפה שהם נמצאים (מה שהם עשו נשאר, ואפשר לבטל אותו), ומבטלת את אלה שממתינים. עם שחקן, רק את שלו; עם `all` או בלי כלום, של כולם. |
| `/enhanced build list` | מציגה את הקסמים שעובדים או ממתינים בשרת: השחקן, הקסם, המימד, כמה אחוזים בוצעו וכמה בלוקים. |
| `/enhanced build history <player>` | מציגה את הצעדים של השחקן, מהישן לחדש, ממוספרים מ-1: "1. מילוי, 140 בלוקים, לפני 2 דקות, עולם רגיל". הצעדים שהוא ביטל (אלה ש-Ctrl + Y יכול לבצע שוב) באים אחרונים. |
| `/enhanced build rank <player> [1-10]` | מציגה את הדרגה והאימון של בילי. עם מספר היא קובעת את הדרגה (האימון שלו הופך למספר של אותה דרגה, או נשאר מעליו אם היה גבוה יותר והדרגה עולה, והמד שלו מתמלא עד הקצה החדש). עובדת רק על בילי. |
| `/enhanced build meter <player> <value>` | קובעת את מד הקסם של בילי (0 עד הקצה של הדרגה שלו). עובדת רק על בילי. |
| `/enhanced build forget <player>` | מנקה את ההיסטוריה והכיס של קסם הבנייה של השחקן, מהזיכרון ומהדיסק. |
| `/enhanced ward list` | מציגה כל מגן הגנה של [ספר הווישאנטי](Sorcerers-Books-HE#ספר-הווישאנטי) בשרת: של מי, השם שלו, איפה הוא (באיזה עולם) ועד כמה הוא מגיע. |
| `/enhanced ward remove <player>` | מורידה כל מגן הגנה של השחקן (הבסיסים שלו נשארים כמקומות שמורים רגילים). מגנים נשמרים עד ששוכחים את הבסיס שלהם, ולכן זו הדרך של האופרטור להוריד אחד. |
| `/enhanced road status [player]` | כמה מבחנים של [דרך המכשפות](Witches-Road-HE) שחקן ניצח, אם הוא בדרך, וכמה פעמים הוא נפל. בלי שחקן: אתם. |
| `/enhanced road enter <players> [trial]` | שולחת שחקנים אל הדרך מיד, בלי צורך בגן (הדרך של אופרטור לבדוק). `trial` הוא 1 (הפרקור), 2 (להעתיק את המבנה) או 3 (מירוץ הקרח); בלעדיו הם מתחילים במבחן שהגיעו אליו. |
| `/enhanced road leave <players>` | מוציאה שחקנים מהדרך, חזרה למקום שבו נכנסו, ושומרת את הגן וההתקדמות שלהם. |
| `/enhanced road reset <players> [newcourse]` | שוכחת את ההתקדמות שלהם בדרך; עם `newcourse` הם גם מקבלים מסלולים חדשים. |
| `/enhanced road skip <players>` | מנצחת במבחן שהם נמצאים בו (או סופרת את הבא כמנוצח). |
| `/enhanced road set <players> <won>` | קובעת כמה מבחנים הם ניצחו (0 עד 99). |
| `/enhanced road layout [player]` | מראה איפה נקודות השמירה, הסיום והשער של המבחן של שחקן. |
| `/enhanced road cells` | כמה מקומות של הדרך בשימוש או בניקוי, וכמה שחקנים בדרך. |
| `/road leave` | **כל אחד** יכול להשתמש בה: יוצאת מדרך המכשפות, ושומרת את הגן וההתקדמות. |
| `/road status` | **כל אחד** יכול להשתמש בה: כמה מבחנים ניצחתם. |

## קסם בנייה: /enhanced build

פקודות `build` הן למפעיל שדואג לבונים: הן משתמשות באותם כללים בטוחים כמו ה-Ctrl + Z של הגיבורים עצמם. כל אחת מהן נותנת שם של שחקן **מחובר** (השם הוא ארגומנט של שחקן, כמו ב-`/tp`); ההיסטוריה עצמה בדיסק, וצעד שכבר לא בזיכרון נקרא בחזרה לפי הצורך.

* **`undo`** מבטלת צעדים של שחקן אחד אחד, מהחדש לישן, גם צעד מיום אחר, כל עוד הוא עדיין בהיסטוריה שלו. כל צעד רץ כקסם של אותו שחקן, בתור מאחורי מה שהוא עושה, והאדווה רצה אחורה, והתשובה אומרת כמה צעדים נכנסו לתור ("בוטלו 3 קסמים של סטיב"). בלוק שמישהו שינה מאז נשאר כמו שהוא (השחקן מקבל הודעה כמה), וחלק שמוגן עכשיו אפשר לנסות שוב אחר כך. צעד שאי אפשר לקרוא את הקובץ שלו מדלגים עליו.
* **`stop`** היא בלם החירום לקסם שאוכל את הזמן של השרת: הוא נעצר איפה שהוא נמצא ומשאיר את מה שעשה. `/enhanced build list` מראה מה עובד.
* **`rank`** ו-**`meter`** הן רק לבילי (לכל אחד אחר הן אומרות "הוא לא בילי"): `rank` מציגה או קובעת את הדרגה שלו (1 עד 10, או עד `build_magic_billy.maxRank` של השרת), `meter` קובעת כמה קסם יש לו ברגע זה.
* **`forget`** מוחקת את ההיסטוריה והכיס של שחקן, מהזיכרון ומהדיסק (`data/enhanced/build/<מזהה>/` בתיקיית העולם): משתמשים בה כשההיסטוריה של שחקן אחד גדלה. (שחקן שעזב לתמיד: מוחקים את התיקייה שלו שם כשהשרת כבוי.)

| דוגמה | מה היא עושה |
|---|---|
| `/enhanced build undo Steve` | מבטלת את הקסם האחרון של סטיב. |
| `/enhanced build undo Steve 5` | מבטלת את חמשת האחרונים שלו. |
| `/enhanced build stop all` | עוצרת כל קסם בשרת. |
| `/enhanced build rank Eilon 4` | הופכת את בילי לוויקאן. |
| `/enhanced build rank Eilon 10` | הופכת את בילי לאדון הכאוס. |
| `/enhanced build meter Eilon 0` | מרוקנת לו את המד. |

## הסתכלות על האנימציות: /enhanced_anim

`/enhanced_anim` היא סוג אחר של פקודה. היא פועלת רק במשחק שלכם, לא צריכה הרשאות אופרטור ולא משנה שום דבר אצל אף אחד אחר. היא נועדה להסתכל מקרוב על האנימציה של הגיבורים, למשל כדי לצלם תנוחה. הפקודות פועלות עליכם (כשאתם גיבור), או על שחקן אחר שבטווח הראייה עם `target`.

| פקודה | מה היא עושה |
|---|---|
| `/enhanced_anim play <gesture>` | מתחילה אצלכם תנועה, לא משנה מה אתם עושים, למשל `THOR_SHATTER`, `THOR_PIN` או `WANDA_SHIELD_RAISE`. המשחק מציע את השמות תוך כדי הקלדה. אם מוסיפים טיק (0 עד 100), התנועה קופאת עליו. |
| `/enhanced_anim hold <ticks>` | קופצת בכל תנועה שמתנגנת לטיק הזה (0 עד 100) ומקפיאה את האנימציה. |
| `/enhanced_anim release` | נותנת לאנימציה לרוץ שוב. |
| `/enhanced_anim fly <s> <u> <turn>` | מעמידה פנים שאתם עפים במהירות `s` (1 היא שיוט, 2 ספרינט), עולים או יורדים `u` (-1 צלילה, 1 עלייה) ופונים `turn` מעלות בכל טיק (-20 עד 20), כדי לראות את התנוחה בלי לעוף מהר כל כך. `/enhanced_anim fly off` חוזרת לתעופה האמיתית שלכם. |
| `/enhanced_anim stance <stance> on` | מכריחה תנוחה מוחזקת (כמו `SHIELD_WANDA` או `THOR_BEAM`) להיות דלוקה. עם `off` היא מוכרחת להיות כבויה, עם `auto` המשחק מחליט, ו-`/enhanced_anim stance off` מחזירה כל תנוחה למצב הרגיל. |
| `/enhanced_anim target <name>` | גורמת לפקודות לפעול על שחקן אחר שבטווח הראייה ולא עליכם. `/enhanced_anim target self` חוזרת אליכם. |
| `/enhanced_anim state` | מציגה או מסתירה את המספרים שמאחורי התנוחה. |

## הסתכלות על הבוסים: /enhanced_model

גם `/enhanced_model` פועלת רק במשחק שלכם, לא צריכה הרשאות אופרטור ולא משנה שום דבר אצל אף אחד אחר. היא מציגה העתק של בוס, או של משהו מהקרב שלו, שרק אתם רואים, כדי שמי שמצייר יוכל להסתכל עליו מקרוב. `/enhanced_model list` מראה מה אפשר להציג, ו-`/enhanced_model clear` מסירה את ההעתק.

* `/enhanced_model <thanos|thanos_phantom|thanos_sword|thanos_meteor|thanos_orb> <state> [tick]` מציגה את הטיטאן המטורף במצב מסוים (`idle`, ו-`idle_2` עד `idle_5` לפי האבנים שהוא מחזיק, `broken`, `barrier`, `veil`, `surge`, `stagger`, `falling`, `arriving`, `dying`) או בטיק של אחד המהלכים שלו (`sword_sweep`, `power_blast`, `infinity_beam`...), את האשליה שלו, את החרב שלו, מטאור או את כדור ההפיכה לאבן.
* `/enhanced_model <ultron|ultron_sentry|vibranium_key> <state> [tick]` מציגה את אולטרון במצב מסוים (`idle`, `volley`, `beams`, `dive`, `pull`, `call`, `punch`, `stagger`, `lift`, `transfer`, `death`, `awakening`, `hybrid`, `ultron3`...), זקיף או את מפתח הוויברניום.
* `/enhanced_model apocalypse <state> [tick]` מציגה את אן סבאח נור במצב מסוים (`idle`, `awakening`, `tell_lance`, `tell_wave`, `tell_spikes`, `tell_boulders`, `tell_entomb`, `tell_mind_crush`, `tell_portal`, `backhand`, `tell_tornado`, `staggered`, `hover`, `escaping`, `kneeling`, `armour_fall`, `dying`, `withdrawing`, `true_<state>` לגוף השברירי, `dying_fire`, והמצבים של המגן `shield_up`, `shield_cracked`, `shield_forming`, `shield_reforming` ו-`shield_broken`); `sand_cocoon`, `sand_lance` ו-`sand_boulder` מציגות את הפקעת, חנית וסלע שלו.
* `/enhanced_ultron_fx <effect> [ticks]` מנגנת אפקט אחד של הקרב מול אולטרון (סימן מקדים, קרן, טבעת, ההתרכבות...) כמה בלוקים לפניכם, רק אצלכם; שום דבר לא נשלח לשרת. האפקטים של גוף, כמו `beams_fire`, צריכים גוף שמוצג עם `/enhanced_model ultron`.
