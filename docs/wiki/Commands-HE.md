# פקודות

כל הפקודות מתחילות ב-`/enhanced` והן ל**אופרטורים** (רמת הרשאה 2): בעלי שרתים ושחקנים שיכולים להשתמש ב-`/gamemode`. הכוחות של גיבורים הם קבועים, ולכן הפקודות האלה הן גם הדרך היחידה להוריד כוח.

| פקודה | מה היא עושה |
|---|---|
| `/enhanced power get [player]` | מראה איזה כוח יש לשחקן. בלי שחקן, היא מראה את שלכם. |
| `/enhanced power set <players> <power> [look]` | נותנת כוח או מורידה אותו, ואפשר ישר לאחד המראות שלו. |
| `/enhanced look <players> <look>` | משנה את המראה של כל שחקן שלגיבור שלו יש את המראה הזה. |
| `/enhanced hex list` | מציגה את כל ההקסים במימד הנוכחי (הבעלים, המיקום, הרדיוס וכמה שחקנים מורשים להיכנס). |
| `/enhanced hex clear` | מפרקת את כל ההקסים במימד הנוכחי. |

## כוחות

הארגומנט `<power>` הוא אחד מאלה:

| כוח | גיבור |
|---|---|
| `none` | בלי כוחות (מוריד את הגיבור של השחקן) |
| `magneto` | [מגנטו](Magneto-HE) |
| `scarlet_witch` | [מכשפת השני](Scarlet-Witch-HE) |
| `quicksilver` | [קוויקסילבר](Quicksilver-HE) |
| `vision` | [ויז'ן](Vision-HE) |
| `tommy` | [טומי](Tommy-HE) |
| `billy` | [בילי](Billy-and-the-Witches-Road-HE) |
| `loki` | [לוקי](Loki-HE) |
| `thor` | [ת'ור](Thor-HE) |

הפקודה מציעה את השמות בזמן ההקלדה. שחקן שמקבל כוח מתעורר בתור הגיבור, עם הכותרת, הצליל וההודעה לכולם, בדיוק כאילו הרוויח אותו. אם לשחקן כבר יש את הכוח הזה ונותנים מראה, רק המראה משתנה.

## מראות

הארגומנט `[look]` או `<look>` הוא המזהה של מראה (ראו [מראות](Looks-HE)):

| גיבור | מזהי המראות |
|---|---|
| ויז'ן | `vision`, `white_vision` |
| טומי | `halloween`, `tracksuit`, `speed`, `own` |
| בילי | `wiccan`, `teen`, `halloween`, `comics`, `own` |
| לוקי | `loki`, `tva`, `god_of_stories`, `own` |
| ת'ור | `thor`, `ragnarok`, `love_and_thunder`, `mighty_thor`, `own` |

למגנטו, למכשפת השני ולקוויקסילבר אין מראות לבחור. `/enhanced look` מדלגת על שחקנים שלגיבור שלהם אין את המראה, והיא נכשלת עם "מראה לא מוכר" אם לאף שחקן מהרשימה אין אותו.

## דוגמאות

| פקודה | מה היא עושה |
|---|---|
| `/enhanced power get Steve` | אומרת לכם איזה כוח יש לסטיב. |
| `/enhanced power set Steve thor` | הופכת את סטיב לת'ור. |
| `/enhanced power set @a loki tva` | הופכת כל שחקן ללוקי, במראה של הווריאנט של ה-TVA. |
| `/enhanced power set Steve none` | מורידה מסטיב את הכוח. |
| `/enhanced look Steve white_vision` | מעבירה את סטיב, שהוא ויז'ן, למראה של ויז'ן הלבן. |
| `/enhanced hex list` | מציגה את ההקסים במימד שלכם. |
| `/enhanced hex clear` | מפרקת את כולם. |

## קישורים

* המספרים של האיזון נמצאים בהגדרות השרת: [הגדרות שרת](Server-Configuration-HE).
* שחקנים בקריאייטיב ובספקטייטור אף פעם לא נהרגים מאבן התודעה או מקיר ההקס, ויכולים להרים כל מיולניר בלי להיות הבעלים שלו. ראו [שאלות נפוצות](FAQ-HE).
