# חפצים ויצירה

כל החפצים שאפשר להשתמש בהם נמצאים בטאב היצירתי **Enhanced**. שבעה מהם מכינים, ושלושה מוצאים בתיבות (או שהם נופלים מיצורים). בתרשימי המתכונים שלמטה, `.` הוא משבצת ריקה, והמתכונים הם **עם צורה**: החפצים חייבים לשבת בדיוק כמו בציור.

## חפצים שמכינים

| חפץ | הופך ל... | פותח את המתכון בספר המתכונים |
|---|---|---|
| [הקסדה של מגנטו](#הקסדה-של-מגנטו) | [מגנטו](Magneto-HE) | הרמת בלוק נד'רייט |
| [הכתר של וונדה](#הכתר-של-וונדה) | מפעיל את הטרנספורמציה של [מכשפת השני](Scarlet-Witch-HE) | הרמת מטיל זהב |
| [המשקפיים של קוויקסילבר](#המשקפיים-של-קוויקסילבר) | [קוויקסילבר](Quicksilver-HE) | הרמת סוכר |
| [ליבת סינתזואיד](#ליבת-סינתזואיד) | [ויז'ן](Vision-HE) (עם השרביט של לוקי) | הרמת כוכב נד'ר |
| [דלת דרך המכשפות](#דלת-דרך-המכשפות) | [טומי או בילי](Billy-and-the-Witches-Road-HE) (עם גן) | הרמת עין אנדר |
| [מיולניר](#מיולניר) | [ת'ור](Thor-HE) (אם ראויים) | הרמת ליבה כבדה |
| [סטורמברייקר](#סטורמברייקר) | כלום: כל אחד יכול להחזיק בו | הרמת כוכב נד'ר |

### הקסדה של מגנטו

<div dir="ltr">

```
N N N
N . N
```

</div>

* N = בלוק נד'רייט (Block of Netherite)

חובשים אותה והופכים ל[מגנטו](Magneto-HE). היא מגינה כמו סט נד'רייט מלא (20 שריון, 12 קשיחות, 40% עמידות לנוקבק), חוסמת בחילה, ואף פעם לא נשברת.

### הכתר של וונדה

<div dir="ltr">

```
G R G
G . G
```

</div>

* G = מטיל זהב (Gold Ingot)
* R = בלוק רדסטון (Block of Redstone)

ניתן למכשפת השני כשהיא מתעוררת, ואפשר להכין אותו אם הלך לאיבוד. עליה: 20 לבבות והגנה כמו שריון יהלום. הוא אף פעם לא נשבר. על כל אחד אחר הוא סתם כתר.

### המשקפיים של קוויקסילבר

<div dir="ltr">

```
S I S
G D G
```

</div>

* S = סוכר (Sugar)
* I = מטיל ברזל (Iron Ingot)
* G = זגוגית (Glass Pane)
* D = בלוק יהלום (Block of Diamond)

מרכיבים אותם והופכים ל[קוויקסילבר](Quicksilver-HE). הם מגינים כמו קסדת ברזל ואף פעם לא נשברים.

### ליבת סינתזואיד

<div dir="ltr">

```
R N R
N S N
R N R
```

</div>

* R = בלוק רדסטון (Block of Redstone)
* N = מטיל נד'רייט (Netherite Ingot)
* S = כוכב נד'ר (Nether Star)

גוף סינתטי שמחכה לתודעה. מחזיקים אותה ביד אחת ומשתמשים בשרביט של לוקי עם היד השנייה, ואתם הופכים ל[ויז'ן](Vision-HE).

### דלת דרך המכשפות

<div dir="ltr">

```
A L A
T E T
A L A
```

</div>

* A = רסיס אמטיסט (Amethyst Shard)
* L = פנס נשמות (Soul Lantern)
* T = דלת סתרים מעץ אלון כהה (Dark Oak Trapdoor)
* E = עין אנדר (Eye of Ender)

דלת שמניחים שטוחה ברצפה. פותחים אותה כשגן מכשפת השני ביד: ראו [בילי ודרך המכשפות](Billy-and-the-Witches-Road-HE). גרזן שובר אותה הכי מהר, בוכנות לא יכולות לדחוף אותה, וכששוברים אותה היא נופלת שוב כדלת.

### מיולניר

<div dir="ltr">

```
N S N
N H N
. R .
```

</div>

* N = מטיל נד'רייט (Netherite Ingot)
* S = כוכב נד'ר (Nether Star)
* H = ליבה כבדה (Heavy Core)
* R = מוט בריז (Breeze Rod)

רק הראויים יכולים להרים אותו, והוא קשור לשחקן הראוי הראשון שעושה את זה (בתיאור שלו כתוב "ללא בעלים" עד אז, ואחר כך "שייך ל-" ושם הבעלים). 10 נזק (איטי, כמו גרזן), אף פעם לא נשבר, אש ולבה לא יכולות לפגוע בו. ראו [ת'ור](Thor-HE).

### סטורמברייקר

<div dir="ltr">

```
N N
N S
. L
```

</div>

* N = מטיל נד'רייט (Netherite Ingot)
* S = כוכב נד'ר (Nether Star)
* L = כל גזע עץ

גרזן שמכה חזק יותר מכל גרזן אחר (12 נזק), אף פעם לא נשבר ולא נשרף. כל אחד יכול להחזיק בו, וכל מי שמחזיק בו יכול לקרוא לביפרוסט. ראו [ת'ור](Thor-HE).

## חפצים שמוצאים בעולם

את שלושת אלה אף פעם לא מכינים. כל סיכוי הוא **לכל תיבה שנוצרת** (או לכל הריגה, ביצורים): לתיבה מהסוג הזה יש את הסיכוי הזה להכיל את החפץ.

### גן מכשפת השני

נדיר מאוד. לבד הוא לא עושה שום דבר: מחזיקים אותו כשנוגעים באבן התודעה ([מכשפת השני](Scarlet-Witch-HE)) או כשפותחים את דלת דרך המכשפות ([בילי ודרך המכשפות](Billy-and-the-Witches-Road-HE)).

| מקור | סיכוי |
|---|---|
| תיבה בוודלנד מנשן | 5% |
| תיבה בספרייה של סטרונגהולד | 4% |
| תיבה במסדרון של סטרונגהולד | 2% |
| תיבה בצומת של סטרונגהולד | 2% |
| תיבה במבצר נד'ר (Nether Fortress) | 3% |
| תיבת אוצר בבסטיון | 5% |
| תיבה באנשנט סיטי | 4% |
| תיבת אוצר באנד סיטי | 5% |
| תיבה במקדש ג'ונגל | 3% |
| תיבה בפירמידת מדבר | 2% |
| מכשפה (Witch), כששחקן הורג אותה | 1% (+0.5% לכל רמה של Looting) |
| אבוקר (Evoker), כששחקן הורג אותו | 2% (+1% לכל רמה של Looting) |

בערימה אחת יש עד 16 גנים.

### השרביט של לוקי

אבן התודעה נמצאת בקריסטל הכחול של הלהב הזהוב שלו. נוגעים בה כשהגן ביד השנייה והופכים למכשפת השני, עם ליבת סינתזואיד והופכים לוויז'ן, ובלי אף אחד מהם **מתים**. הוא גם נשק חזק לקרב מקרוב (8 נזק, אף פעם לא נשבר).

| מקור | סיכוי |
|---|---|
| תיבת אוצר באנד סיטי | 10% |
| תיבה בספרייה של סטרונגהולד | 5% |
| תיבת אוצר בבסטיון | 4% |
| תיבה באנשנט סיטי | 3% |
| תיבה בוודלנד מנשן | 3% |

### הטסרקט

אבן החלל בקובייה שלה. כשמשתמשים בו כשחקן בלי כוח הופכים ל[לוקי](Loki-HE), רחוק משם; גיבור שמשתמש בו קופץ לבלוק שהוא מסתכל עליו. הוא אף פעם לא נגמר.

| מקור | סיכוי |
|---|---|
| תיבת אוצר באנד סיטי | 8% |
| תיבה בספרייה של סטרונגהולד | 6% |
| תיבה בוודלנד מנשן | 5% |
| תיבה באנשנט סיטי | 4% |

## שינוי השלל

הסיכויים שלמעלה הם *global loot modifiers* של NeoForge בתוך הנתונים של המוד (`data/enhanced/loot_modifiers/`), ולכן דאטה-פק יכול לשנות אותם. המתכונים הם קובצי מתכון רגילים (`data/enhanced/recipe/`).
