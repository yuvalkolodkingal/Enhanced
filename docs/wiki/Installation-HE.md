# התקנה

## מה צריך

| | |
|---|---|
| **מיינקראפט** | Java Edition 1.21.1 |
| **טוען מודים** | NeoForge 21.1.256 ומעלה (הקו 21.1.x הוא זה של מיינקראפט 1.21.1) |
| **ג'אווה** | 21 (המשגר של מיינקראפט כבר כולל אותה) |
| **להתקין אותו על** | הלקוח, ובמולטיפלייר גם על השרת |

במולטיפלייר המוד מוסיף חפצים, בלוק, יצורים ומקשים, ולכן השרת וכל שחקן שמצטרף צריכים את אותה גרסה שלו.

## התקנת המוד

1. מתקינים **NeoForge** למיינקראפט 1.21.1 (ההתקנה נמצאת ב-[neoforged.net](https://neoforged.net/)) ומפעילים את המשחק פעם אחת עם הפרופיל של NeoForge, כדי שתיווצר תיקיית `mods`.
2. מורידים את קובץ ה-jar החדש ביותר מדף ה-[Releases](https://github.com/yuvalkolodkingal/enhanced/releases). זו הגרסה המסומנת *Latest*, ושמה דומה ל-`enhanced-1.0.0-build.12.jar`. (כדי לבנות את ה-jar בעצמכם, ראו [בנייה מקוד המקור](Building-from-Source-HE).)
3. שמים את ה-jar בתיקיית `mods` שבתוך תיקיית המיינקראפט:
   * ווינדוס: `%appdata%\.minecraft\mods`
   * מק: `~/Library/Application Support/minecraft/mods`
   * לינוקס: `~/.minecraft/mods`
4. מפעילים את מיינקראפט עם הפרופיל של NeoForge. *Enhanced* מופיע ברשימת המודים, וטאב יצירתי בשם **Enhanced** מכיל את כל החפצים.

## התקנה על שרת

שמים את אותו jar בתיקיית `mods` של שרת NeoForge 21.1 ומפעילים אותו. שחקנים צריכים את המוד גם בלקוח שלהם כדי להצטרף. עולם יחיד-שחקן עובד כמו שרת משלו.

## מה המוד יוצר בהפעלה הראשונה

| מה | איפה | בשביל מה |
|---|---|---|
| תיקיית המוזיקה | `config/enhanced/music/` בתיקיית המיינקראפט (עם `README.txt` קצר) | שמים שם שיר כדי להחליף את השיר של הווקמן של קוויקסילבר או של ספיד, או את המוזיקה של דרך המכשפות, במשחק שלכם. ראו [מוזיקה](Music-HE). |
| תיקיית המוזיקה של העולם (3.5) | `<world>/serverconfig/enhanced/music/` (עם `README.txt`), נוצרת כשהשרת עולה | שירים שם מחליפים את השירים של הווקמן ואת המוזיקה של הדרך לכל השחקנים, שמורידים אותם לבד. ראו [מוזיקה](Music-HE#המוזיקה-של-העולם-עצמו-שרתים). |
| הגדרות שרת | `world/serverconfig/enhanced-server.toml`, נוצר כשהעולם נטען בפעם הראשונה | כל המספרים של המוד. ראו [הגדרות שרת](Server-Configuration-HE). |
| מקשים | *Options, Controls, Enhanced Powers* | חמשת מקשי היכולות ומקש החלפת המראה. ראו [שליטה ומקשים](Controls-HE). |

## עדכון

מחליפים את ה-jar הישן שבתיקיית `mods` בחדש (בלקוח ובשרת). הגיבור שלכם, המראה שלכם והמקומות השמורים של הביפרוסט נשמרים עם השחקן. **ב-3.5 צריך לעדכן את השרת ואת כל השחקנים ביחד** (פרוטוקול רשת 9): שחקן 3.4 לא יכול להיכנס לשרת 3.5, ולהפך.

## לשימוש אישי בלבד

הווקמן של קוויקסילבר יכול לנגן את *Sweet Dreams (Are Made of This)* של יוריתמיקס (Eurythmics) (מאז 3.5 רק אם בוחרים בו; כברירת מחדל מתנגן השיר שלו עצמו), וההקלטה מובנית בתוך ה-jar. היא מוגנת בזכויות יוצרים, ולכן המאגר וקבצי ה-jar שנבנים ממנו הם לשימוש אישי בלבד. שומרים את המאגר פרטי ולא מפיצים את ה-jar ברבים.

## פתרון בעיות

| בעיה | מה לנסות |
|---|---|
| "Missing mod" או שאי אפשר להצטרף לשרת | מתקינים את אותו jar בלקוח ובשרת. |
| המשחק אומר ש-NeoForge ישן מדי | מעדכנים את NeoForge לגרסה 21.1.256 ומעלה. |
| המקשים לא עושים כלום | המקשים עובדים רק לגיבור, כשאין מסך פתוח. ראו [איך הופכים לגיבור](Becoming-a-Hero-HE), ובדקו את המקשים ב-*Options, Controls, Enhanced Powers*. |
| אני לא מצליח להרים את מיולניר | ראו [שאלות נפוצות](FAQ-HE) ו[ת'ור](Thor-HE). |
| השיר של קוויקסילבר לא מתנגן | השיר מתנגן כל עוד זמן קוויקסילבר דלוק (לוחצים R), בין אם קוויקסילבר רץ ובין אם לא, ו**התכופפות + R** מדליקה ומכבה את הווקמן. מהירות על (G) לבדה לא מנגנת שיר. שיר משלכם חייב להיות קובץ `.mp3`, `.ogg` או `.wav` בתיקייה `config/enhanced/music/`. ראו [מוזיקה](Music-HE). |
